# ページのグラレコを描く

グラレコは、そのページの**メッセージ 1 つ**を、ホワイトボードに黒い太ペンで描いたような**ゆるい絵**で伝えるもの。
文字のカードでも、揺らした製図でもない。

## 手順

1. **メッセージを 1 文で決める。** ページを読み、読者に持ち帰ってほしいことを 20 字前後の 1 文にする
   （例: 「hook が送ったとき、Application はまだある」）。これが絵の題になる。2 文要るなら、削る。
   完了条件: 1 文を声に出して言え、ページの結論と食い違わない。
2. **主役の絵を 1 つ選ぶ。** その 1 文を、ページの仕組みそのものの絵で言う。時系列なら時間軸、
   関所なら壁、取りこぼしなら落ちる封筒、というように**ページごとに構図を変える**。人物＋吹き出し＋
   パネルのような共通の型に流し込まない。完了条件: 他のページのグラレコと並べて、構図が違う。
3. **描く。** 下の画風と SVG の決まりに従い、md の冒頭（題と `>` の要約の直後）に生の SVG で書く。
4. **ビルドしてスクリーンショットで見る。** 下の「確かめる」で撮り、画風の点検表を全部通す。
   通らない項目があれば 3 に戻る。完了条件: 点検表が全部 yes で、スクリーンショットのパスを報告に書ける。

## 画風

- **主線は黒の太いマーカー 1 本。** 線幅 6〜8、丸い線端・丸い角。細い線で精密に組まない
- **ゆるく描く。** 直線・正円・正確な矩形は使わず、少し曲がった手描きのパス（`C` / `Q`）で描く。
  角はずらし、線は閉じ切らなくてよい
- **描き込みは少なく。** 主役の絵 1 つ＋脇役 2〜3 個まで。図形（パス）はおおむね 15 本以内。
  説明の文字は題を除いて 5 か所以内、1 か所 10 字前後
- **色は強調にだけ。** 青は「うまくいく流れ」、赤は「落とし穴」、黄は蛍光ペンの下線。
  色付きの要素は 1 枚に 3 つまで。塗りは淡く、主線は黒のまま
- 背景は白（ホワイトボード）。題は大きく（28〜34px）、蛍光ペンの下線を引く

## SVG の決まり

```html
<div class="grwb">
<svg class="wb" viewBox="0 0 1000 560" role="img" aria-label="（メッセージの 1 文と、絵の説明）">
  <path class="hl" d="..."/>                       <!-- 題の下線（黄） -->
  <text class="th" x=".." y="..">題</text>
  <g filter="url(#wob)"> ...主線（class="pen"）... </g>
  <text x=".." y="..">短い文字</text>
</svg>
</div>
```

- クラスは `docs/build_argocd_notify.py` の CSS（`.grwb` の節）にある。主線 `pen`、色線 `pen-b` / `pen-r`、
  淡い塗り `fb` / `fr` / `fw`、矢じり `marker-end="url(#pk)"`（黒）/ `#pb`（青）/ `#pr`（赤）
- `<defs>`（揺らしフィルタ `#wob`、矢じり）と白い背景はビルドが差し込む。md には書かない
- 文字は `<g filter>` の外に置く（揺らすと読めなくなる）
- `aria-label` にメッセージを書く。絵が読めない人にも同じことが伝わるように

## リポジトリの制約

- HTML は自己完結。外部 CDN・Web フォント・JS・画像ファイルを使わない（`CLAUDE.md`）
- 手書きフォントは Yomogi（OFL）。`docs/src/argocd-notify/fonts/yomogi-pool.woff2` から、
  ページの `class="wb"` の SVG で使う字だけをビルドが抜き出し、base64 で埋め込む。
  プールに無い字（①〜⑥ など）はビルドが警告する。その字は使わず言い換える
- ビルドは `uv run docs/build_argocd_notify.py`。2 回目で差分が出ないこと

## 確かめる

ホストのブラウザは依存ライブラリが無くて起動しないので、Playwright の Docker イメージで撮る。

```bash
docker run --rm -v "$PWD/docs/site/argocd-notify:/site:ro" -v "$OUT:/out" \
  mcr.microsoft.com/playwright/python:v1.63.0-noble bash -c \
  "pip install -q playwright==1.63.0 && python /out/shot.py hooks.html hooks.png"
```

`shot.py` は `.grwb` の要素だけを撮る数行のスクリプトで、作業用の一時ディレクトリに置く（リポジトリに置かない）。

点検表（スクリーンショットを見て全部 yes にする）:

- 1 文のメッセージが、題と絵の両方から読み取れるか
- 主線が太い黒で、手で描いたように見えるか（製図に見えないか）
- 色付きの要素は 3 つ以内で、強調の箇所だけか
- 文字が線や枠と重なっていないか、枠からはみ出していないか
- 他のページのグラレコと構図が違うか

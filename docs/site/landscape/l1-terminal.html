Claude Code 勢いあり

層L1・エージェント本体提供Anthropicライセンスproprietarystar148,591直近リリース2026-09-29

何をするものか

ターミナルに常駐し、リポジトリを読んで理解したうえでコードを書く Anthropic 純正のエージェント。 2025-02 にリサーチプレビューとして出て、Claude 4 世代と同時に一般提供された。 IDE 統合を主戦場にせず、シェルの中で完結させる路線を最初に大きく広めた側にあたる。

向いている用途

既存リポジトリへの変更。ファイルを跨ぐリファクタや、テストを回しながら直していく作業。 MCP でツールを足せるので、社内システムを触らせる用途にも寄せられる。

注意点

モデルは Anthropic に固定される。他社モデルを使いたい場合は L2 のプロキシを挟むことになり、 実際 claude-code-router のようなツールはそこを埋めるために生まれている。 GitHub のリポジトリは issue 受付と配布が主で、エージェント本体のソースは公開されていない。

他ツールとの関係

Codex CLI・Gemini CLI・Copilot CLI と同じ「ベンダー純正ターミナルエージェント」の枠。 モデル非依存を掲げる OpenCode とは設計思想が正面から違う。

他ツールとの関係

後発のターミナルエージェントの多くが、ここで確立された「差分を当てて commit する」流儀を踏襲している。

OpenClaw 勢いあり

何をするものか

コーディング専用ではない。 自分のマシンや小さな VPS に置いて動かす汎用のパーソナルエージェントで、 メールやカレンダー、チャットなど多数のツールを呼べる。 エージェントの人格・規則・権限を SOUL.md というマークダウン 1 枚で定義する設計が特徴。

2025-11 の登場から 1 年足らずで、GitHub で最も star を集めたソフトウェアリポジトリの一つになった。 この一覧の中で star が突出して多いのはこれ。

注意点

この表の中で、性格が最もずれている項目。 コーディングエージェントとして並べると誤解を生む。 ここに載せているのは、Headroom の対応リストに入っていたという母集団の決め方に従った結果であって、 「コーディングツールとして有名だから」ではない。 権限が広いぶんセキュリティ上の検討事項も多いと繰り返し指摘されている。

他ツールとの関係

他ツールとの関係

Claude Code や OpenCode と同じ L1 に並ぶ代替のハーネス。Headroom はこのエージェント向けの 差し込み（Headroom プラグイン群の hermes）を同梱している。

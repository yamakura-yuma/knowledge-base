## 何をするものか

手順書をフォルダ単位でまとめ、必要になったときだけエージェントに読ませる仕組み。
説明文と本体を分けておき、関係しそうなときだけ本体を開かせることで、
常時コンテキストを圧迫しないようにする発想。

## 向いている用途

長く複雑だが、使う場面が限られている手順。社内固有の運用フローなど。

## 注意点

**AGENTS.md と違ってベンダー固有。** AAIF に寄贈された MCP や AGENTS.md と異なり、
Anthropic 発の仕組みのまま中立化していない。他社エージェントへの移植性は形式次第。

## 他ツールとの関係

ponytail のようなサードパーティのスキル集がこの形式で配られており、
apm はそれをパッケージとして配布する側に立つ。

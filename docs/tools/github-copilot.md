## 何をするものか

2021 年に補完機能として始まった、この分野の最古参。
以後 chat、agent mode、coding agent と守備範囲を広げ、
現在は単一の機能ではなく Copilot ブランドの製品群の総称になっている。

## 向いている用途

GitHub を中心に開発が回っている組織。issue から PR までを同じ画面で完結させたい場合。

## 注意点

「Copilot」が指すものが年によって違うので、記事を読むときは時期の確認が要る。
技術プレビューだった Copilot Workspace は 2025-05 に終了し、知見は agent mode と coding agent に吸収された。

## 他ツールとの関係

2026-02 からは Claude と Codex を Copilot の中から選べるようになり、
**「エージェントの実行面」と「モデル・エージェントの実体」が分離する**方向に動いている。
この一覧の層構造で言えば、L1 の中でさらに受け皿と中身が割れつつある。

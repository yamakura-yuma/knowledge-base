## 何をするものか

VS Code をフォークして作られた AI 前提のコードエディタ。
補完・チャット・エージェントをエディタ本体に統合し、「エディタごと置き換える」路線の代表格になった。

## 向いている用途

GUI での編集を主軸に置きつつ、エージェントにも任せたい場合。
VS Code の操作感と拡張資産をそのまま持ち込める。

## 注意点

公開リポジトリが無いため、**この一覧の star / リリース指標には載っていない**。
表で「指標なし」になっているのは活動が無いという意味ではない。

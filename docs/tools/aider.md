## 何をするものか

この分野で最も古い部類の OSS エージェント。変更を git のコミット単位で積んでいく設計で、
「エージェントが何をしたか」を後から git の履歴として追えるのが一貫した思想。
付属する polyglot ベンチマークは、モデルのコーディング性能を語るときの共通指標として広く引かれている。

## 向いている用途

変更履歴を細かく残したい作業。モデルを選ばず BYOK で使いたい場合。

## 注意点

**リリース頻度が明確に落ちている。** GitHub Releases は 2025-08 で止まっているが、
PyPI には 2026-02 に v0.86.2 が出ており、リポジトリへの push もその後まで続いている。
つまり停止ではなく減速。ただし週次で出ていた往時のペースではない。
表の「直近リリース」列だけを見て判断すると実態を見誤る例として、この一覧では分かりやすい。

## 他ツールとの関係

後発のターミナルエージェントの多くが、ここで確立された「差分を当てて commit する」流儀を踏襲している。

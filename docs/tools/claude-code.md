## 何をするものか

ターミナルに常駐し、リポジトリを読んで理解したうえでコードを書く Anthropic 純正のエージェント。
2025-02 にリサーチプレビューとして出て、Claude 4 世代と同時に一般提供された。
IDE 統合を主戦場にせず、シェルの中で完結させる路線を最初に大きく広めた側にあたる。

## 向いている用途

既存リポジトリへの変更。ファイルを跨ぐリファクタや、テストを回しながら直していく作業。
MCP でツールを足せるので、社内システムを触らせる用途にも寄せられる。

## 注意点

モデルは Anthropic に固定される。他社モデルを使いたい場合は L2 のプロキシを挟むことになり、
実際 `claude-code-router` のようなツールはそこを埋めるために生まれている。
GitHub のリポジトリは issue 受付と配布が主で、エージェント本体のソースは公開されていない。

## 他ツールとの関係

Codex CLI・Gemini CLI・Copilot CLI と同じ「ベンダー純正ターミナルエージェント」の枠。
モデル非依存を掲げる OpenCode とは設計思想が正面から違う。

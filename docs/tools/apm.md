## 何をするものか

エージェント向けの指示・スキル・MCP サーバーを、依存関係とロックファイルつきで配布する CLI。
Microsoft 製。`apm.yml` に宣言し、`apm install` で対象のエージェント（Claude Code など）の
設定ディレクトリへ展開する、という npm 的な使い勝手を取る。

## 向いている用途

複数のマシンやリポジトリで、同じエージェント設定を揃えたい場合。
サードパーティのスキル集を、コピペではなくバージョン指定で取り込みたい場合。

## 注意点

star の規模は他の L3 項目に比べるとまだ小さい。この分野自体が固まっていないので、
配布形式が今後も同じとは限らない。

## 他ツールとの関係

Agent Skills や AGENTS.md が「形式」を決めるのに対し、apm は「配り方」を担当する。
層としては同じ L3 だが役割が違い、**ここが L3 をもう一段割れそうに見える理由の一つ**になっている。

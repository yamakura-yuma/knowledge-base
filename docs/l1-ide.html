Cursor 指標なし手動で詳細に指定

層L1・エージェント本体提供Anysphereライセンスproprietary手動昇格の理由L1/IDE の代表格だが公開リポジトリが無い

何をするものか

VS Code をフォークして作られた AI 前提のコードエディタ。 補完・チャット・エージェントをエディタ本体に統合し、「エディタごと置き換える」路線の代表格になった。

向いている用途

GUI での編集を主軸に置きつつ、エージェントにも任せたい場合。 VS Code の操作感と拡張資産をそのまま持ち込める。

注意点

公開リポジトリが無いため、この一覧の star / リリース指標には載っていない。 表で「指標なし」になっているのは活動が無いという意味ではない。

他ツールとの関係

同じ枠には Windsurf がいたが、2026-06 に Devin Desktop へ改名して名前が消えた。 ターミナル側の Claude Code / OpenCode とは、どこを主戦場にするかで分かれている。

GitHub Copilot 指標なし手動で詳細に指定

層L1・エージェント本体提供GitHubライセンスproprietary手動昇格の理由この分野の最古参で比較の基準点になるが公開リポジトリが無い

何をするものか

2021 年に補完機能として始まった、この分野の最古参。 以後 chat、agent mode、coding agent と守備範囲を広げ、 現在は単一の機能ではなく Copilot ブランドの製品群の総称になっている。

向いている用途

GitHub を中心に開発が回っている組織。issue から PR までを同じ画面で完結させたい場合。

注意点

「Copilot」が指すものが年によって違うので、記事を読むときは時期の確認が要る。 技術プレビューだった Copilot Workspace は 2025-05 に終了し、知見は agent mode と coding agent に吸収された。

他ツールとの関係

2026-02 からは Claude と Codex を Copilot の中から選べるようになり、 「エージェントの実行面」と「モデル・エージェントの実体」が分離する方向に動いている。 この一覧の層構造で言えば、L1 の中でさらに受け皿と中身が割れつつある。

Zed 勢いあり

何をするものか

Atom と Tree-sitter の作者陣が作った高性能エディタ。 もともとは速度と共同編集を売りにしており、エージェント機能は後から載せた側にあたる。 リポジトリ自体は 2021 年からあり、この一覧で最も古い。

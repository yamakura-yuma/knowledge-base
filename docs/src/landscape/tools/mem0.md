## 何をするものか

Mem0 社が作る、AI アシスタントやエージェントに差し込む記憶層。会話から利用者の好みや事実を
抽出して保存し、次の会話で関係する記憶を検索して文脈に足す。記憶はユーザー・セッション・
エージェントの単位で持てる。

2026-04 に記憶の抽出方式を改め、LLM を 1 回だけ呼び、記憶を追加だけする方式（更新・削除をせず、
上書きせずに積み増す）に変えた。検索は意味・キーワード（BM25）・エンティティを組み合わせる。

## 向いている用途

チャットボットやアシスタントに、利用者ごとの好みや過去のやり取りを持ち越させたい場合。
README の用途例は顧客サポート、個人アシスタント、医療、生産性ツールなど、利用者を相手にする製品が中心。

## 注意点

提供形態は 3 つある。ライブラリ（`pip install mem0ai`）、Docker Compose で立てる自前のサーバー、
マネージドのクラウドで、README の比較表では高度な機能はクラウドにしか全部は入らない。

ライブラリは LLM と埋め込みモデルを必要とし、既定はどちらも OpenAI（従量課金の API キーが要る）。
ほかのプロバイダにも差し替えられる。

## 他ツールとの関係

Graphiti・cognee・Letta と同じ「エージェントの記憶」の系統で、会話から記憶を積む。
文書から一括でグラフを作る GraphRAG・LightRAG・graphify とは用途が違う。
Claude Code などのコーディングエージェント向けには、SDK の使い方を教える Agent Skills を配っている。

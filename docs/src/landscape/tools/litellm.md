## 何をするものか

100 以上のプロバイダを OpenAI 互換のインタフェースに正規化する OSS ゲートウェイ。
ライブラリとしても、独立したプロキシサーバとしても使える。近年は Rust コア + Python SDK の構成。

## 向いている用途

自社インフラ内にゲートウェイを置きたい場合。
モデル呼び出しのコード側を OpenAI 互換で書き切ってしまい、裏側を運用で差し替えたい場合。

## 注意点

自分で動かす以上、可用性とアップグレードの責任は自分に来る。
対応プロバイダが多いぶん、個々のプロバイダ固有機能の追従度には差がある。

## 他ツールとの関係

OpenRouter の「自前でホストする版」と考えると位置づけが掴みやすい。
Headroom は LiteLLM をバックエンドとして呼べるようになっており、層の中でさらに積み重なる関係にある。

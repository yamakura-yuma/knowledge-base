## 何をするものか

Oraios AI が作る、コーディングエージェント向けの MCP サーバー。IDE と同じようにシンボル単位で
コードを扱う道具（シンボルの検索、参照元の検索、シンボル本体の置き換え、リネームなど）を
エージェントに渡す。行番号や文字列検索ではなく、言語の意味構造に沿って読み書きさせるのが狙い。

裏側の解析は 2 通りから選ぶ。既定は各言語の Language Server（LSP）で、40 以上の言語に対応する。
もう一つは有料の JetBrains プラグインで、こちらは移動・インライン化・デバッガ操作まで使える。

## 向いている用途

大きめのコードベースで、ファイルをまたぐリネームや参照の洗い出しをエージェントにさせたい場合。
README は、Claude Code・Codex CLI・Copilot CLI にタスクをさせて付加価値を測った評価を載せている
（評価したのは開発元自身）。

## 注意点

`uv` で入れ、`serena init` のあと MCP クライアントに起動コマンドを登録する。README は
MCP・プラグインのマーケットプレイス経由で入れないよう明記している（載っている手順が古いため）。
言語によっては Language Server を別に入れる必要がある。

Claude Code や Codex の中で使うと、ファイル操作・検索・シェルの基本ツールは既定で無効になる
（ハーネス側の道具と重なるため）。セッションをまたぐ記憶の仕組みも持つが、無効にできる。

ライセンスは部品ごとに分かれていて、本体は GPL-3.0-or-later、LSP の抽象化層（SolidLSP）は MIT。

## 他ツールとの関係

CodeGraph と同じく「探索の回数を減らす」側のツール。CodeGraph が事前に作った索引を引くのに対し、
Serena は起動中の Language Server に都度問い合わせる。`headroom wrap` を使うと既定で入る
（`--code-memory none` で止まる）。

## 何をするものか

Microsoft Research の研究プロジェクト。非構造のテキストから LLM でエンティティと関係を抽出して
ナレッジグラフを作り、そのグラフを使って質問への回答用の文脈を組み立てる。
データの前処理（索引づけ）と、それを引く問い合わせの 2 段に分かれ、どちらも CLI から回せる。

## 向いている用途

手元の非公開文書の集まりについて、個々の断片ではなく全体を横断した問いに答えさせたい場合。
公式ドキュメントは、既定のプロンプトのままでは良い結果が出にくいとして、
データに合わせたプロンプトの調整を強く勧めている。

## 注意点

README は索引づけが高コストになりうると警告し、手順とコストを読んでから小さく始めるよう
勧めている。取り込む量に比例して LLM を呼ぶため、従量課金の API では費用が嵩む。

2026-08 に README へ告知が入り、プロジェクトは実質的に保守モードになった。新しい PR と新機能は
受け付けず、バグ修正と依存関係の更新（特に CVE 対応）だけを続ける。コードは実演用で、
Microsoft の正式にサポートされた製品ではないとも明記している。

マイナーバージョンが上がるたびに `graphrag init --force` で設定を作り直す必要があり、
メジャーバージョンでは移行用のノートブックを流さないと再索引になる。

## 他ツールとの関係

「文書から一括でグラフを作る」系統の本家筋。LightRAG はこれを軽くした系統で、graphify も
同じ発想に立つ。会話から増分で記憶を積む Graphiti・Mem0・cognee とは、グラフを作る単位が違う。

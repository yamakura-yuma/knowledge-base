## 何をするものか

エージェントにプロジェクト固有の指示 — コーディング規約、ビルド手順、テストの流し方 — を渡すための
共通ファイル形式。ルートに `AGENTS.md` を置くだけ、という徹底した単純さが普及の理由になっている。

もとは Codex が「指示をどこから読むか」を決める必要から OpenAI が作ったもので、
2025-12 に AAIF へ寄贈されて中立化した。リポジトリも `openai/` から `agentsmd/` へ移っている。

## 向いている用途

複数のエージェントを使い分けている環境。ツールごとに別々の設定ファイルを書き分けなくて済む。

## 注意点

形式が決まっているのは「置き場所と名前」までで、中身の書き方は規定されていない。
エージェントごとに読み方の解釈が揺れる余地は残る。

## 他ツールとの関係

Anthropic の Agent Skills が「必要なときだけ読ませる手順書」なのに対し、
AGENTS.md は「常に読ませる前提の一枚」という違いがある。両者は排他ではない。

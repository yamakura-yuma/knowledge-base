## 何をするものか

Nous Research の自己改善型エージェント。複雑な作業のあとにスキルを自動で作り、
使うたびに直していく学習の回路を持つと README は謳う。過去の会話の検索や、
Telegram などから話しかけてクラウドの VM で作業させる使い方も前提にしている。

## 向いている用途

ラップトップに縛られず、常駐させたエージェントに記憶とスキルを溜めさせたい場合。

## 注意点

Claude で動かすなら Anthropic の API キー（従量課金）を渡す。Claude のサブスクリプションの
OAuth は Claude Code など Anthropic 純正アプリ向けで、他社のアプリに Claude のログインを
組み込んだり、Free / Pro / Max の資格情報で要求を中継したりすることは規約が認めていない。
サブスクリプションで Claude Code を使っている環境からは、そのまま乗り換えられない。

## 他ツールとの関係

Claude Code や OpenCode と同じ L1 に並ぶ代替のハーネス。Headroom はこのエージェント向けの
差し込み（Headroom プラグイン群の hermes）を同梱している。

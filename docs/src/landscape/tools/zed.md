## 何をするものか

Atom と Tree-sitter の作者陣が作った高性能エディタ。
もともとは速度と共同編集を売りにしており、**エージェント機能は後から載せた側**にあたる。
リポジトリ自体は 2021 年からあり、この一覧で最も古い。

## 向いている用途

エディタとしての速度を優先しつつ、エージェントも使いたい場合。

## 注意点

エージェント専用ツールと比べると、エージェント機能の歴史は浅い。

## 他ツールとの関係

Cursor が「VS Code をフォークして AI を入れた」のに対し、Zed は「独自エディタに AI を足した」。
出自が違うので、比較するときは前提を揃える必要がある。

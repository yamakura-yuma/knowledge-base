## 何をするものか

Topoteretes が作る、エージェント向けの OSS の記憶基盤。文書・コード・会話を取り込み、
テキストはエンティティ・関係・検索用の断片に、コードはシンボルと依存関係のグラフにして持つ。
問い合わせ時にはグラフ・ベクトル・コードの文脈から関係するものを選んで返す。

操作は `remember`（記憶する）・`recall`（引き出す）・`improve`（フィードバックやセッションの内容を
グラフに反映する）・`forget`（消す）の 4 つ。Python・TypeScript の SDK、REST API、MCP サーバーのほか、
Claude Code と Codex 向けのプラグインがある。

## 向いている用途

エージェントにセッションをまたいだ長期の記憶を持たせたい場合。文書とコードと会話を同じ
グラフに入れたいときに、Graphiti や Mem0 より守備範囲が広い。

## 注意点

README は API キー無しでローカルに動くと謳う。その場合の抽出はローカルの GLiNER モデルと
ローカルの埋め込みモデルで行い、LLM を使う改善の段は飛ばされ、回答文の生成はしない。
付属の GLiNER 抽出器はデモ扱いで、精度の高い版は商用の問い合わせ先に誘導している。
LLM のキーを設定すると既定は OpenAI になり、処理と回答のたびにプロバイダを呼ぶ。

グラフ・ベクトル・セッション・メタデータを Postgres 1 つにまとめる構成は、README 上ではデモ機能で、
本番向けはライセンス製品とされている。

## 他ツールとの関係

Graphiti・Mem0・Letta と同じ「エージェントの記憶」の系統。README はそれらからの記憶の移行手段を
案内している。文書から一括でグラフを作る GraphRAG・LightRAG・graphify とは、増分で積み続ける点が違う。

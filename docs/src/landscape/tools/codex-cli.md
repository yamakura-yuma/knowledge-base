## 何をするものか

OpenAI 純正の軽量ターミナルエージェント。ChatGPT のサブスクリプションでそのまま動くのが大きい。
同じ Codex ブランドでクラウド実行面も持っており、ローカルとクラウドで同じ名前の別物が並んでいる点は
最初に混乱しやすい。

## 向いている用途

ChatGPT を既に契約している環境で、追加の API 課金なしにエージェントを試したいとき。
Apache-2.0 なので中身を読んで挙動を確かめられる。

## 注意点

クラウド版はタスクごとにネットワークを遮断する設計で、依存パッケージの取得ができない。
ローカル版とクラウド版でできることが違うので、記事を読むときはどちらの話か確認する必要がある。

## 他ツールとの関係

AGENTS.md はもともと Codex がプロジェクト固有の指示を見つけるために必要として生まれた形式で、
のちに AAIF へ寄贈されて他社エージェントの共通形式になった。

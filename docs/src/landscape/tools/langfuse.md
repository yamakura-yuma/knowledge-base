## 何をするものか

OSS の LLM 観測・評価基盤。トレースの収集、評価、プロンプト管理を一つにまとめる。
自分でホストすることも、クラウド版を使うこともできる。

## 向いている用途

エージェントが何をどの順に呼んだかを後から追いたい、あるいは評価を回したい場合。

## 注意点

Claude Code との公式連携は、要求の経路に挟まるプロキシではない。Stop hook に登録した
スクリプトが応答のたびに会話ログを読み、ターン・生成・ツール呼び出しをトレースとして送る。
記録はプロジェクトごとの環境変数で有効にする。観測先のサーバーを別に用意する必要がある。

## 他ツールとの関係

Helicone と同じく観測寄りだが、Helicone がゲートウェイとして経路に入るのに対し、
Langfuse の Claude Code 連携は経路の外で後から記録する。

## 何をするものか

Rust 製のローカルファースト・エージェント。CLI とデスクトップアプリの両方を持つ。
MCP を前提に設計されており、拡張は MCP サーバを足す形で行う。

Block が開発していたが、**2025-12 に Linux Foundation 傘下の AAIF 創立プロジェクトの一つとなり、
2026-04 にリポジトリと運営が実際に移管された**（`block/goose` → `aaif-goose/goose`）。

## 向いている用途

特定ベンダーに寄りたくない場合。ローカルモデルを含め、繋ぐ先を自分で決めたい場合。

## 注意点

移管に伴いドキュメントの所在も変わっている。古い URL を参照している記事が多いので、
設定を調べるときは移管後の公式を見ること。

## 他ツールとの関係

**中立財団に移った数少ないエージェント本体。** MCP・AGENTS.md と並ぶ AAIF 三本柱の一角で、
L1 にいながら L3 の標準化の流れと直接繋がっている点が他のエージェントと違う。

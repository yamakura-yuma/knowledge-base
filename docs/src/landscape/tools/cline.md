## 何をするものか

BYOK を前提にした OSS エージェント。VS Code 拡張として広まり、
現在は CLI と SDK も持つ。モデルを自分で選べることを一貫して売りにしている。

## 向いている用途

使うモデルとコストを自分で管理したい場合。IDE 内で作業を完結させたい場合。

## 注意点

BYOK なので、コストの上限管理は自分の責任になる。

## 他ツールとの関係

**この系譜からフォークが多数出た。** Roo Code（旧 Roo Cline）と Kilo Code が代表で、
Roo Code が 2026-05 に終了した際には、チーム自身が移行先として Cline を挙げている。

## 何をするものか

もとは Claude Code のリクエストを他社モデルへ向けるために生まれたツール。
現在は複数のエージェントを束ねるローカル制御面を名乗り、モデル横断のルーティングや
ツールのオーケストレーションまで守備範囲を広げている。MIT。

## 向いている用途

ベンダー純正エージェントの使い勝手を保ったまま、裏のモデルだけ差し替えたい場合。

## 注意点

純正クライアントの想定外の使い方にあたるため、本家の更新で壊れる可能性が構造的にある。
利用規約との関係も自分で確認する必要がある。

## 他ツールとの関係

「エージェント本体はベンダー純正、モデルは自由」という需要を埋める位置。
最初からモデル非依存の OpenCode とは、同じ需要に別の方向から答えている。

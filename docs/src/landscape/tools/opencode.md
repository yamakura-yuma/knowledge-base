## 何をするものか

OSS のコーディングエージェント。MIT ライセンスで、モデル提供元に縛られないことを最初から掲げている。
TUI とプラグイン機構を持ち、プロバイダ設定を差し替えることで任意の OpenAI 互換エンドポイントに向けられる。
star の数はこの一覧の L1 で最多クラス。

## 向いている用途

使うモデルを自分で決めたい場合。OpenRouter のようなルーターを挟んで、
タスクごとにモデルを切り替える構成と相性がいい。プラグインで独自ツールを足すこともできる。

## 注意点

名前が紛らわしい。2025 年の分裂で Go 実装側は Charm の **Crush** として続いており、
この OpenCode は TypeScript で作り直された側にあたる。
さらに **OpenClaw** という別物もあるので、検索するときは取り違えに注意。
運営元も SST から **Anomaly** に改称しており、リポジトリは `anomalyco/opencode` に移っている。

## 他ツールとの関係

L2 のゲートウェイと組み合わせる前提で設計されているので、OpenRouter や LiteLLM、Headroom と繋ぐ話が多い。

## 何をするものか

モデルとツール・データを繋ぐための接続規格。2024-11 に Anthropic が公開し、
1 年ほどで各社のエージェントが揃って実装する事実上の標準になった。
2025-12 に Linux Foundation 傘下の **Agentic AI Foundation (AAIF)** へ寄贈され、
特定ベンダーの持ち物ではなくなっている。

## 向いている用途

エージェントに社内システムを触らせるとき。一度 MCP サーバとして書けば、
対応するどのエージェントからも同じように使える。

## 注意点

規格が広く使われるぶん、権限設計の責任はサーバ側に来る。
エージェントに何を渡すかは MCP 自体が決めてくれるわけではない。

## 他ツールとの関係

L3 の中でも土台の位置にある。goose のように MCP を前提に設計されたエージェントもあれば、
後から対応した製品もある。AAIF では AGENTS.md・goose と並ぶ創立時の三本柱の一つ。

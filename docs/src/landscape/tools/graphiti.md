## 何をするものか

Zep が作る、時間の流れを持つナレッジグラフ。エージェントとの会話や入力を「エピソード」として
取り込み、事実ごとに有効期間を持たせて、古くなった事実を自動で無効にする。
検索は埋め込み・キーワード（BM25）・グラフ探索の組み合わせ。

## 向いている用途

利用者や状況について、時間とともに変わる事実をエージェントに持ち越させたい場合。

## 注意点

Neo4j・FalkorDB などのグラフ DB と、取り込み用の LLM・埋め込みのプロバイダが要る。
既定は OpenAI で、Anthropic を使う場合も API キーを渡す（従量課金）。
README は GraphRAG との比較表で、静的な文書の要約を GraphRAG の用途として自分と区別しており、
手元の文書やコードを要約・索引する用途には向かない。

## 他ツールとの関係

Mem0・cognee・Letta と同じ「エージェントの記憶」の系統。文書から一括でグラフを作る
GraphRAG・LightRAG・graphify とは、増分で更新し続ける点が違う。

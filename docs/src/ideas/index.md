# アイデア — まだ試していない構想の置き場

> 構想を書き留めておく場所。確認済みの事実と、まだ試していない仮説を区別して書く。

このリポジトリには、実測で裏を取れたものだけを書くという縛りがある。`ideas/` はその例外で、
まだ試していない構想を置く。**例外にするかわりに、主張の一つ一つに印を付ける。**
一次資料（公式 docs、issue、手元の CLI の `--help`）で裏を取ったものは
[確認済み]、まだ試していないもの・推測を含むものは [未確認] とする。
[未確認] は「試せば確かめられる問い」なので、各ページの末尾に次に何を試すかを書く。
確かめた結果は同じページの印を書き換えて反映し、構想が固まったら `tool-research/` などの
調査の話題へ移す。
